3 Taxonomy application

To facilitate the application of our taxonomy, we have designed a user guide[1]. This guide streamlines the identification and analysis of shape control methods, and includes user-friendly questions as well as metrics and example values for quantitative analysis. While our taxonomy is exhaustive enough to cover existing and upcoming methods, the public repository format allows users to collaborate and provide updates that accommodate unforeseen future developments.

One of the main challenges in shape control is to fairly compare methods. This requires aligning their characteristics according to our taxonomy's main criteria. Specifically, aligning system characteristics (Sec. 2.1) enables comparisons of methods with shared scope. Similarly, aligning error definition criteria (Sec. 2.3) across methods establishes uniform metrics for measuring success or failure.
