# Taxonomy of Deformable Object Shape Control

To access the Taxonomy and the user-friendly guide **[visit the pages site https://nachocz.github.io/Taxonomy-of-deformable-object-shape-control/index.html](https://nachocz.github.io/Taxonomy-of-deformable-object-shape-control/index.html)**

This repository provides a structured framework for the characterisation of deformable object shape control methods. The complete taxonomy guide, paper content, and practical examples are available on the website above.
